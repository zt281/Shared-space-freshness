# 以统一共享空间连接本地与跨网络插件

Tyche 的核心目标是让同机与跨市场策略采用相同的插件逻辑拓扑，因此采用统一逻辑共享空间、完整版本显式发布及每份权威状态单写者的访问契约。用户接受以该接口替代跨机器普通指针透明访问，并以普通网络作为首版跨机部署基础、RDMA 作为后续可选加速，从而保留统一插件模型而不绑定专用网络硬件。传输和副本同步仍需实现与测量；零拷贝不作为消除跨境传输或一致性成本的承诺，具体边界及故障恢复决议见 [部署边界与前端离线行为](../../.scratch/tyche-architecture/issues/01-deployment-lifecycle.md#answer)。
