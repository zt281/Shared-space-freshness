# 共享基础拟合结果并独立计算策略报价

多个期权策略需要消费同一份市场拟合结果，并按各自选定的持仓范围调整报价，因此将共享拟合结果的发布与策略报价状态分开：拟合实例拥有基础曲面及其配置，策略拥有自身的报价偏移和结果。该取舍引入了明确的事件、输入和参数版本依赖，使共享计算不把某个策略的持仓风险传给其他消费者；它不要求拟合与报价采用特定进程或节点部署。已接受的算法、数据和成交触发契约记录在[期权定价、曲面拟合与参数状态](../../.scratch/tyche-architecture/issues/14-option-pricing-model.md)的 Q53–Q68，剩余参数与安全曲面问题仍在该问题中讨论。
