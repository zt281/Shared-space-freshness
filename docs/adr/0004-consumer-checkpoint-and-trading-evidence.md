# 分离计算检查点与交易恢复证据

允许消费者纯计算领先于一致保存的状态与输入位置，通过保留确切输入及计算版本在崩溃后重放；以有界合批减少逐事件保存成本。交易意图、身份、风险占用和停止意愿具有独立的持久边界，不能因计算检查点滞后而丢失或重复执行；恢复只重建状态，交易放行仍需当前核对和有效性检查。

检查点前发布的结果必须有稳定身份及恢复确切版本所需证据才能支持交易。保存失败、恢复证据缺失或未保存工作达到边界时限制相关新单；具体契约和确认记录见[访谈](../../.scratch/tyche-architecture/analysis/consumer-checkpoint-contract.md)。这选择了更多恢复关联工作，换取不必在每次计算后同步整个检查点；不取消发单前保存交易证据的要求。
