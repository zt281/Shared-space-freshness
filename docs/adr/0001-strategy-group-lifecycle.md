# 以策略组隔离故障并更新代码

Tyche 首版以策略组作为约定的故障影响和代码更新范围：单个 C++ 策略故障可使所属组停止，其他组继续运行；更新策略代码时允许暂停目标组。这个选择接受组内共同停止和更新暂停，使同一交易任务中的策略可以协调停止，同时保留其他组的运行能力，不要求首版提供无缝代码接管。

参数调整采用不同流程：运行中校验整套参数后，在事件处理边界切换版本，同一轮报价使用同一版本。具体进程/线程方案、组内挂单处置和重启状态恢复留给后续架构决策。

讨论与范围见 [策略运行方式与性能预算](../../.scratch/tyche-architecture/issues/04-strategy-performance.md)。
