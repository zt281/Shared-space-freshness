## Answer

2026-09-14，经用户 Q4–Q9 明确取舍及 [官方能力研究](../research/binance-equity-short-access.md)，本项接入选择已解决。研究资产中的“候选/待选择”描述是研究阶段状态，最终产品选择以本 Answer 为准；本项不代表账户或交易验证完成。

### 首版范围与选择理由

采用 Binance USDT 股票永续，覆盖符合条件的美股及韩国公司相关合约。用户接受衍生品卖出开仓，目的为无已有多头时建立空头并进行双边做市；实际借券不再是必要路径，不将该需求称作裸空。首版使用现有个人 Binance 账户及 USDT，不要求新开美元券商账户；CTP 商品与股指期货期权继续使用 CNY。

产品目录动态发现，按产品类型、USDT 计价/保证金、交易状态及账户权限筛选，活动合约继续由策略配置选择并受已验证容量限制。SKHYNIXUSDT 与 SAMSUNGUSDT 是已核实公开上架样本，不是硬编码名单；不满足条件的标的可以跳过。不把韩国公司相关合约等同于韩国交易所全覆盖，也不自动扩展到商品、指数或其他 TradFi 产品。

Direct Stocks、bStocks 实际接入继续暂缓；本项取代此前股票必须借券及另选通道的要求。现有 Binance BTC/ETH 期权与 USDT 永续范围保持其原决议效力。

### 接入、部署与领域约束

- 研究证据支持使用 USDⓈ-M HTTPS/WebSocket 市场、订单与账户流接口，作为现有 Binance 接入家族的产品扩展；无需为此引入本地券商桌面网关。具体模块与进程位置仍由部署和后端架构问题决定，生产网络可达性需验证。
- 股票永续表达衍生品持仓、保证金和资金费，不创建虚构借券负债或证券交收。SK 海力士韩国股对应合约与美国 ADR 对应合约分别标识；合约、底层资产与上市地不能仅凭公司名合并。
- 同一 Futures 账户的真实持仓模式、余额和保证金范围按接口核对；不能按股票/加密界面分类擅自拆分或合并资金。具体标记价、指数价、资金费周期、过滤器和限额动态读取。
- 24/7 合约撮合与底层股票交易时段分别建模。是否在底层休市期间做市、参考价失效处置及资金费风险留给 [订单、风控和恢复语义](07-order-risk-recovery.md)，本项不选择具体策略规则。

### 接入验收与尚待验证条件

1. 核对实际账户地区、TradFi 产品开通/协议状态、Futures API 权限、账户持仓模式及每个目标合约的可交易性。尚未验证或权限不足时不得启用相关实盘策略；不得为匹配配置自动签协议或切换账户模式。
2. 从生产公共目录核对产品分类、状态、USDT 资金属性及交易过滤器；Demo 可用于验证流程，但研究已发现分类和样本覆盖与生产不同，不以 Demo 目录代替生产事实。
3. 在适用模拟环境验证从空仓开空、部分成交、撤单、平仓、订单/账户回报和重连查询闭环。测试下单接口不进入撮合，单独成功不代表完整交易验证通过。
4. 在后续已授权接入阶段复核实际网络、限流、未知提交结果处理、动态资金费/保证金及休市行情样本；本轮仅执行公共查询，没有使用凭据、签署协议、切换模式或真实交易。

本项解除部署边界及跨市场领域模型对股票产品选择的阻塞。实际性能保证由性能原型和正式接入验证给出。
