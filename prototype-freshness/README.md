# 共享空间新鲜度 · 可丢弃逻辑原型

双击 `index.html` 打开。无需依赖、服务器或构建；浏览器需支持 `structuredClone`。选择引导场景，按顺序点击，也可自由操作并导出完整会话记录。

第一次理解模型，建议先看 [三张中文解释图](diagrams/README.md)，再操作状态演示。

这是本地两个**逻辑节点**的纯状态模型，不包含 C++、进程间共享内存、网络或持久化。先确认数据有效性与指令行为是否符合使用者预期，随后再推进问题单要求的 C++ 双节点及目标环境验证。示例毫秒阈值不是生产参数，也不是性能结果。

## 布局与模型

- `index.html`：全部样式、界面与逻辑；第一个脚本为独立纯状态模块，第二个脚本为展示和场景。
- 源数据版本、来源业务核验证据和本地收到时间分别建模。普通心跳不更新核验证据；旧视图重传仅改变接收时间。
- “核验未变业务数据”模拟来源完成一次可靠业务核查并发布新证据，不能由副本自行调用来假装来源仍有效。缺口需完整核验快照修复。
- 未发布写入不可见。重启代次、过期指令、结果未知、恢复核对、稳定观察及主动停止分别处理。

## 证明范围

八个引导场景用于人工观察，不是生产测试套件。单文件没有真实线程、内存屏障、版本争用或跨时钟计算；模拟执行不连接交易账户。完整对冲账、成交去重、实际指令传输、C++ 双节点、完整指标持久化、容量及目标部署均尚待验证。
